# Multi-Label Intent Classifier for Google Play Store App Reviews

This is an NLP course project that aims to build a multi-label intent classifier for app reviews from the Google Play Store.

### Project Goal
To classify user reviews into multiple intent categories and analyze sentiment (positive/negative/neutral) using XLNet and VADER.

### Features
- Multi-label classification using fine-tuned XLNet
- Sentiment analysis using VADER
- Streamlit web app interface for real-time predictions

### Work in Progress
- Model training
- Data preprocessing pipeline
- Web app interface
